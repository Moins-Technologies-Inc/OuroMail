- **Find a shared mailbox by name.** Add Shared Mailbox searches your organisation's directory as you type a name or an address, and adds the one you pick in one click, or with the arrow keys and Enter. The directory lists people and shared mailboxes alike, so the one you pick is checked when it is added, as a typed address is. The first search asks your permission to read the directory (`User.ReadBasic.All`), by itself and only after MailCraft asks you; when you or your administrator allowed it already, the first search asks nothing. Not now keeps everything as it was for this session, and File › Info says where it stands, with Ask again. What you type goes to Microsoft only from the dialog, while it is open.
